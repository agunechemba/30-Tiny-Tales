Chapter 14

If It Rains

Conditionals and Branching

🌦️

Every morning Zainab looked at the sky. If it rained, she took an umbrella. If it was sunny, she took sunglasses. Then she went to school.

"You are using a conditional," said Mum. "Your day splits like a road. If it rains, go this way. Else, go that way." Programmers call this a branching statement. The simplest is the IF-THEN statement: if a Boolean expression is true, run one set of instructions; otherwise, skip them. Add an ELSE and the computer is forced to follow one path or the other.

Zainab saw forks everywhere. At the traffic light: if green, walk. Else, wait. In her game: if score is 100, you win. Else, keep playing.

Sometimes there are three roads: if rain, umbrella. Else if cold, scarf. Else, sunglasses. This is an IF-THEN-ELSEIF statement. When there are many exact values to check, programmers use a SELECT CASE (or switch) statement instead of a long chain of IFs.

"The computer is not clever," said Mum. "It just checks the question and takes the right road." That question is a Boolean expression — something either true or false, like (4 < 54) or (score == 100).

Big Idea

If something is true, do this. Else, do that. This is called a conditional. Programs use conditionals to react to data — without them, a program does the same thing every time no matter what.

Try It!

Make an if/else for a traffic light. If green, what? If red, what? What about yellow? Now make it an if/elseif/else with three roads.
