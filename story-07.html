Chapter 7

Numbers, Words and Yes-or-No

Data Types

🔢

Three friends moved into the computer. Num loved counting things: 3, 42, 1000. Word loved letters: “hello”, “pizza”, “Zanzibar”. And Bool could only ever say two things — true or false — but he said them with enormous confidence.

One day someone asked, “What is 2 + 3?” Num said 5, quick as a flash. Then Word tried it. “Two plus three,” said Word proudly, “is… twenty-three!” Everyone stared. Word had glued the symbols together instead of adding them.

“That’s because you’re a string,” said Num kindly. “You join things end to end. I’m a number, so I actually add.” Bool nodded wisely. “True,” he said.

Each type has its own job. A number can be counted with. A string can be read aloud. A boolean can answer a question.

Big Idea

The three basic data types are number (3, 7.5), string (text in quotes, like “hi”) and Boolean (true or false).

Try It!

Sort these into number, string or Boolean: 12, “cat”, true, “42”, false, 3.5. Careful — “42” has quotes, so it’s a string!
