Chapter 20

The Calabash Inside the Calabash

Recursion

🏺

Aisha opened a big calabash. Inside was a smaller one. She opened that one. Inside was a smaller one still! And inside that one — another!

"How many are there?" she asked. Grandma said, "Open one, then ask the one inside. It will ask the one inside it." Aisha laughed. "But that never stops!"

"It stops," said Grandma, "because the tiniest calabash does not open. It just says 'one.' That is the base case."

So the big one said "one plus what is inside." The next said the same. Until the tiny one said "one." Then the answers ran back up. A function that calls itself is called recursion. It always needs a base case to stop.

Big Idea

Recursion is when something calls itself. It always needs a base case so it can stop.

Try It!

Count down out loud: "3, then count from 2, then count from 1, then count from 0 — stop!" Which part was the base case?
