## Why this project exists

Most programming tutorials start with a screen, a blinking cursor, and the words *"Hello, World."*

That works for some kids. But many — especially younger ones — need something warmer first: a story, a character, a little problem worth solving. They need to *feel* the idea before they type it.

**The Coding Storybook** was built to fill that gap. It takes the 21 core ideas of programming — from decomposition to object-oriented design — and turns each one into a short, illustrated tale a parent or teacher can read aloud in five minutes.

No laptop required. No prior knowledge. Just a story.

---

## What's inside

Each chapter is a self-contained story with three parts:

- 📖 **The Story** — a friendly character runs into a small, relatable problem.
- 💡 **The Big Idea** — a plain-language explanation of the concept the story just showed.
- ✏️ **Try It!** — a tiny offline activity to make the idea stick.

The 21 chapters walk through:

| | | |
|---|---|---|
| 1. Computational thinking | 2. Programs & sequence | 3. Code, statements, syntax |
| 4. Input / output | 5. Bugs & debugging | 6. Variables |
| 7. Data types | 8. Operators | 9. Conditionals |
| 10. Loops | 11. Testing | 12. Functions |
| 13. Events & handlers | 14. Lists & arrays | 15. Strings |
| 16. Scope & lifetime | 17. Modules & APIs | 18. Data structures |
| 19. Algorithms | 20. Recursion | 21. Object-oriented basics |

## Who it's for

- **Parents** who want a gentle, screen-light way to introduce tech ideas.
- **Teachers** looking for five-minute warm-ups or reading-circle material.
- **Kids aged roughly 7–12** who are curious about "how the computer knows."
- **Anyone** who learns better through narrative than through documentation.

---

## How it works

The site is deliberately simple:

- **Pure HTML, CSS and JavaScript.** No frameworks, no build tools, no tracking.
- **One page per story**, all linked from a single table of contents.
- **Progress is remembered** in your browser's local storage, so kids can see how far they've read.
- **Arrow keys turn pages** — like a real book.
- **Works offline** once loaded, and looks good on phones and tablets.

You can open it in any browser and start reading immediately.

---

## Design philosophy

The look is intentionally **analog**: cream paper, dashed borders, soft shadows, a big coral drop cap on every story. It should feel like a book a child might pull off a shelf, not like a dashboard.

The writing follows three rules:

1. **One idea per story.** Never two.
2. **No jargon before the story earns it.** The term arrives *after* the child already understands the concept.
3. **Every story ends with something to do.** Reading is the beginning, not the end.
