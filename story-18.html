Chapter 18

The Backpack, the Line and the Plates

Data Structures

🎒

Four friends carried things in different ways.

Map had a backpack with named pockets. "Pencils" went in one. "Snack" went in another. You asked for a pocket by name. Quick! That is a dictionary.

Set had a bag with a rule: no two the same. Two red marbles? Only one went in. "I just want to know if it is in there," said Set.

Stack carried plates. You put one on top. You take one off the top. Last in, first out.

Queue stood in a line at the tap. First in, first out. "Good for taking turns," said Queue.

Big Idea

A map looks things up by name. A set has no duplicates. A stack is last in, first out. A queue is first in, first out.

Try It!

Which is which? The undo button. Jobs waiting for a printer. A phone book. A list of people who already voted.
