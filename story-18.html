Chapter 18

The Backpack, the Line and the Plates

Data Structures

🎒

Four friends each carried their things differently.

Map had a backpack with labelled pockets. “Pencils,” said a pocket, and inside were pencils. “Snack,” said another. Whatever you wanted, you asked for it by name — quick as a blink. That’s a dictionary or map.

Set had a bag with a very strict rule: no duplicates. Two identical marbles? Only one went in. “I only care whether it’s in there or not,” said Set.

Stack carried a pile of plates. You could only add on top and take from the top. Last one in, first one out. “Perfect for undoing a mistake,” said Stack.

Queue stood in a line at the slide. First one in, first one out. “Perfect for taking turns,” said Queue, politely letting the smallest one go first.

Big Idea

Different jobs need different containers: a map looks things up by key, a set keeps only unique items, a stack is last-in-first-out, and a queue is first-in-first-out.

Try It!

Which container for each job? Undo button · a printer’s waiting jobs · a phone book · a list of everyone who has already voted.
